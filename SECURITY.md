# Security policy

## Supported version

Security fixes are evaluated for the latest published `0.1.x` release after publication. This repository currently contains the local `0.1.0` release candidate.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or Security Advisory flow for `cguodesign/proofmarks`. Please include affected version, environment, reproduction steps, impact, and any proposed mitigation. Do not open a public issue for an unpatched vulnerability.

No separate security email address has been designated. Private vulnerability
reporting must be enabled for this repository before the npm release is approved.
