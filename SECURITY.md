# Security policy

## Supported version

Security fixes are evaluated for the latest published `0.1.x` release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or Security Advisory flow for `cguodesign/proofmarks`. Please include affected version, environment, reproduction steps, impact, and any proposed mitigation. Do not open a public issue for an unpatched vulnerability.

[Private vulnerability reporting](https://github.com/cguodesign/proofmarks/security/advisories/new)
is enabled for this repository. No separate security email address has been designated.
